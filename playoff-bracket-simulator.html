Frequently asked questions

How does the simulator pick winners?+

By default it weights the higher seed as more likely to win, but adds randomness so upsets happen — just like real playoffs.

Can I run my own picks?+

Yes. Click any team to advance them. You can mix manual picks with simulated rounds.

Is this a real playoff bracket?+

It is a generic simulator. It does not use live NBA playoff data and is not affiliated with the NBA.
